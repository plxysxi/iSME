## 📁 โครงสร้างไฟล์ทั้งหมดในโปรเจกต์ (File Structure)

เว็บไซต์นี้ได้รับการออกแบบและจัดโครงสร้างแยกไฟล์ออกจากกันอย่างชัดเจนตามที่ผู้ใช้งานต้องการ เพื่อให้เปิดดูและแก้ไขต่อได้ง่ายทันที:

| ชื่อไฟล์ | ชื่อหน้าภาษาไทย | คำอธิบายรายละเอียดของหน้า |
| :--- | :--- | :--- |
| **`index.html`** | **หน้าหลัก (Homepage)** | หน้าแรกของเว็บไซต์ มี Hero Banner สไลด์, สถิติสมาชิก, ไฮไลต์สมาพันธ์, ค่านิยม ENSURE, ข่าวสาร, กิจกรรมสัมมนา และพันธมิตร |
| **`about.html`** | **เกี่ยวกับสมาพันธ์ (About Us)** | ประวัติความเป็นมา, วิสัยทัศน์ (Vision), พันธกิจ (Mission), วัตถุประสงค์ 5 ด้าน, ค่านิยมองค์กร ENSURE และสารจากผู้บริหาร |
| **`news.html`** | **กิจกรรมและข่าวประชาสัมพันธ์ (News & Activities)** | หน้ารวมข่าวสาร กิจกรรม บทความความรู้ พร้อมระบบตัวกรองหมวดหมู่ (เศรษฐกิจ, กิจกรรม, ต่างประเทศ, นโยบาย) |
| **`news-detail.html`** | **รายละเอียดข่าวสาร (News Detail)** | หน้าอ่านบทความข่าวฉบับเต็ม พร้อมรูปภาพปก เนื้อหา ข่าวที่เกี่ยวข้อง และปุ่มแชร์ลงโซเชียลมีเดีย |
| **`services.html`** | **บริการสำหรับสมาชิก (Services & Steps)** | สิทธิประโยชน์สำหรับสมาชิก 6 ด้าน, รายละเอียด 4 ขั้นตอนการสมัครสมาชิก และเครือข่าย 77 จังหวัด |
| **`register.html`** | **แบบฟอร์มสมัครสมาชิก (Member Registration)** | ฟอร์มรับสมัครสมาชิกออนไลน์ พร้อมช่องกรอกข้อมูลธุรกิจ ผู้ประสานงาน แนบเอกสาร และการยินยอม PDPA |
| **`contact.html`** | **ติดต่อเรา (Contact Us)** | ที่อยู่สำนักงานใหญ่, เบอร์โทรศัพท์, อีเมล, Line OA, แผนที่ Google Maps แบบโต้ตอบ, ฟอร์มส่งข้อความ และสำนักงานภูมิภาค 4 ภาค |

## 🗄️ ไฟล์ฐานข้อมูลกลาง (Database File)

### 📌 ตำแหน่งไฟล์: `assets/js/database.js`
ไฟล์นี้ถูกสร้างขึ้นมาเพื่อรวมศูนย์ข้อมูลทั้งหมดของเว็บไซต์ไว้ที่เดียว เพื่อให้คุณสามารถแก้ไขข้อมูลได้ง่าย ไม่จำเป็นต้องแก้โค้ด HTML ทีละหน้า

**สิ่งที่สามารถแก้ไขได้ใน `database.js`:**
1. **`siteInfo`**: ชื่อสมาพันธ์, เบอร์โทร (061-028-4009), อีเมล (info@smethai.or.th), ที่อยู่, เวลาทำการ, Line ID, ลิงก์ Facebook, YouTube, TikTok
2. **`navigation`**: รายชื่อเมนูนำทาง ลิงก์ และคำอธิบายแต่ละหน้า
3. **`heroBanners`**: ข้อความบนแบนเนอร์สไลด์หน้าแรก รูปภาพ และปุ่มกด
4. **`stats`**: ตัวเลขสถิติ (77 จังหวัด, 15,000+ สมาชิก, 100+ พันธมิตร, 250+ โครงการ)
5. **`coreValues`**: ค่านิยมองค์กร 6 ตัวอักษร **ENSURE** (Enhancement, Networking, Sacrifice, Unity, Responsibility, Ethics)
6. **`objectives`**: วัตถุประสงค์ 5 ด้าน (SME Ecosystem, Voice of SME, Connectivity, Innovation, Good Governance)
7. **`membershipBenefits`**: รายการสิทธิประโยชน์สำหรับสมาชิกสมาพันธ์
8. **`registrationSteps`**: 4 ขั้นตอนการสมัครสมาชิก
9. **`news`**: บทความ ข่าวสาร กิจกรรม (หัวข้อ, วันที่, รูปภาพ, จำนวนครั้งที่อ่าน, เนื้อหา, แท็ก)
10. **`upcomingEvents`**: รายชื่องานสัมมนาและนิทรรศการที่กำลังจะมาถึง
11. **`partners`**: รายชื่อองค์กรพันธมิตรภาครัฐและเอกชน
12. **`regionalOffices`**: ข้อมูลศูนย์ประสานงานประจำภาคเหนือ ภาคอีสาน ภาคกลาง ภาคใต้

## 🚀 วิธีการเปิดใช้งานและทดสอบในเบราว์เซอร์ (How to Run)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์เพื่อเปิดดูได้ทันที
คุณสามารถดับเบิ้ลคลิกที่ไฟล์ `index.html` ในโฟลเดอร์นี้เพื่อเปิดดูผ่าน Google Chrome, Microsoft Edge, Safari หรือเบราว์เซอร์ใดก็ได้ทันที

### วิธีที่ 2: รันผ่าน Local Web Server (แนะนำ)
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์นี้แล้วพิมพ์:
```bash
python -m http.server 8000
```
จากนั้นเปิดเบราว์เซอร์ไปที่:
👉 **http://localhost:8000**
